# mmWave Radar Target Tracker

Embedded Controllers course project at Alfred State (Fall 2026, in progress). A compact radar display that tracks moving targets in real time.

## How it works
- An **LD2450 24 GHz mmWave radar sensor** detects up to **3 moving targets** out to **8 m**
- An **ESP32** reads the target coordinates from the sensor
- A **4.2" display** plots each target on a radar-style screen
- Everything is housed in a **3D-printed enclosure** with the sensor mounted externally
